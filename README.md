# Encrypted Fuzzy PID Control

Code and recorded data for **Encrypted Fuzzy PID Control for Privacy-Preserving Cloud-Vehicle Collaborative Trajectory Tracking**, by Peng Zhang, Weizhao Xu and Hengrui Lu.

## Recompute the paper results

Run the following commands from the repository root.

```text
python scripts/recompute_results.py
```

This standard-library command checks file hashes and recomputes Tables 6–10 and 12 and the Section 6.5 control-output errors. Results are written to `reproduced_results/`. It does not run a new simulation or connect to a server.

## Contents

| Folder | Manuscript content |
|---|---|
| `code/` | Vehicle simulation, Stanley steering, plaintext PID/fuzzy/polynomial controllers, RNS-CKKS evaluation, and client/server runners |
| `coefficients/` | The selected 384-cell fit and the four polynomial partitions in Section 6.2 |
| `configs/` | `partitions.json` for the four reported partitions; `expected_results.json` for checking recomputed results |
| `data/` | Route and reference speeds; six main controller runs; four polynomial partitions with a fuzzy reference; four operating conditions with three runs each; matched control-output errors |
| `scripts/` | Metric recomputation, coefficient fitting/evaluation, error reconstruction, plotting and experiment setup |
| `docs/` | Run instructions, data columns, experiment settings, software environment, parameter sources and table-to-data mapping |

Both CKKS-PID and CKKS-Fuzzy-PID use RNS-CKKS implemented through TenSEAL/Microsoft SEAL.

## Fit coefficients, analyze errors and redraw figures

The recorded analysis/client environment uses Python 3.13.9. Install the scientific dependencies before running these commands; the recorded server environment is listed in [Parameter settings](docs/PARAMETER_SOURCES.md).

```text
python -m pip install numpy==2.3.5 matplotlib==3.10.8 tenseal==0.3.16
python scripts/check_error_decomposition.py
python scripts/check_approximation.py
python scripts/check_approximation.py --refit --grid base_8x8x6
python scripts/plot_results.py
```

The approximation script supports exactly the four reported partitions. Coefficients are regenerated by least squares on a 10×8×7 grid in each cell. Original arrays remain under `coefficients/`; regenerated files go to the chosen output directory.

See [Reproduction instructions](docs/REPRODUCING.md) for the five experiment entry points and the separate server/client commands. Recomputed values from saved CSVs should match the paper records; new timing measurements depend on hardware, network and host load.

The vehicle update used by the formal experiments is inside the released runners. `code/lateral_control.py` provides Stanley steering, and `code/main.py` loads/interpolates `data/racetrack_waypoints.txt`. Use `scripts/run_experiment.py` to prepare the matching sources, coefficients and route together.

The Chen comparator implementation, effective controller settings and software environment are documented in [Parameter settings and sources](docs/PARAMETER_SOURCES.md). See [Data columns and units](docs/DATA_DICTIONARY.md) and [Paper-to-file mapping](docs/TABLE_DATA_MAP.md) for the retained experiment records.
